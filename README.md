A one-page newspaper front page that sums up the world news of Friday 20 November 2026 in a single 1024x1024 image: Russia's 400-drone, 110-missile strike on Ukraine with two missiles falling in Poland, the World Court's Rohingya genocide ruling against Myanmar, the Trump-Xi-Putin joint peace declaration in Shenzhen, the biggest UK-EU post-Brexit deal, and the COP31 fossil-fuel deadlock, plus Houthi, Haiti and AI-market briefs in the ticker. main.py copies the committed entry.png to the output directory; render.py is the Pillow program that drew it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The image lands at out/entry.png.
